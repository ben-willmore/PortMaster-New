## Controls
| Button             | Action                          |
| :----------------- | :------------------------------ |
| D-pad              | Forward / back / strafe    WASD |
| A                  | Primary attack             Left |
| B                  | Secondary attack          Right |
| X                  | Jump                      Space |
| Y                  | Crouch                     Ctrl |
| L1                 | Use                           E |
| L2                 | Reload                        R |
| L3                 | Objectives/scores           Tab |
| R1                 | Run/walk                  Shift |
| R2                 | Holster weapon                Q |
| Left stick up/down | Next/previous weapon      Wheel |
| Hotkey+Y           | Quick save                   f5 |
| Hotkey+A           | Quick load                   f9 |

### Quick weapon selection
| Button             | Action                          |
| :----------------- | :------------------------------ |
| L1                 | Pistol                        1 |
| L2                 | Rifle                         2 |
| R1                 | SMG                           3 |
| R2                 | MG                            4 |
| Left stick up      | Grenade                       5 |
| Left stick left    | Heavy                         6 |
| Left stick right   | Papers/binoculars             7 |

## Port details
This is an arm64 build of the unmodified [source code](https://github.com/openmoh/openmohaa/). Graphics settings have been reduced for good performance on low-spec devices, but can be increased using the in-game options.

See [BUILDING.md](https://github.com/PortsMaster/PortMaster-New/blob/main/ports/openmohaa/openmohaa/BUILDING.md) for building instructions.
